# Security policy

## Scope

This repository builds a static website hosted on GitHub Pages. There is no server, database, login or user data. Relevant issues include, for example, cross-site scripting through site content, a compromised dependency or build step, or a weakness in the CI/CD workflow.

Only the latest version (the `master` branch and the live site) is supported.

## Reporting a vulnerability

Please **do not** open a public issue. Report it privately through [GitHub's private vulnerability reporting](https://github.com/ET-CS/et-cs.github.io/security/advisories/new).

Include what you found, how to reproduce it, and the impact you expect. You'll get an acknowledgement within 7 days and updates as it's fixed. Credit is given in the advisory unless you'd rather stay anonymous.
